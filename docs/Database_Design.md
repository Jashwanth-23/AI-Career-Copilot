# Database Design

## Entity Relationship Summary

### Tables
1. `users`: Stores user profile data, credentials, and settings.
2. `resumes`: Stores uploaded resume file references and extracted text.
3. `resume_analyses`: Stores AI analysis scores, feedback, and suggestions.
4. `interviews`: Tracks mock interview sessions and user responses.
5. `roadmaps`: Stores generated career step-by-step roadmaps.
6. `chat_history`: Stores conversations with the AI Career Copilot bot.
