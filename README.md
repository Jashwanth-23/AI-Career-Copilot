# AI Career Copilot

AI Career Copilot is a production-ready, AI-powered SaaS application designed to help job seekers optimize their resumes, prepare for interviews, generate career roadmaps, discover job opportunities, and engage with an interactive AI career advisor.

## Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS, React Router, Axios (Deployment: Vercel)
- **Backend:** FastAPI, SQLAlchemy, PostgreSQL, JWT Authentication, Gemini API (Deployment: Render)
- **Database:** PostgreSQL (Deployment: Neon PostgreSQL)
